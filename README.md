# Laborbook (Web React Application)

A modern, offline-capable workforce attendance, wage calculation, and cash book management platform rewritten from the original Android app.

## Features
- **Staff Attendance & Payroll Engine**: Mark daily attendance (Present, Absent, Half Day, Double P+P, Present + 1/2), calculate overtime hours, track advances, and compute real-time net balances for daily and monthly workers.
- **Cash Book Ledger**: Record site expenses and income with Cash/Online payment tags and running balance calculations.
- **PDF Report Hub & Wage Slips**: Download individual worker monthly wage slips, batch staff rosters, and financial audit statements powered by jsPDF.
- **Master Backup & Migration**: Export and import ultra-lightweight CSV backups preserving worker directories, attendance logs, and transaction ledgers.
- **Bilingual UI**: Full English and Hindi (हिन्दी) localization.
